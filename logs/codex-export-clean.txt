[USER]: what is Locale.ROOT

[CODEX]: `Locale.ROOT` is Java’s language-neutral locale.

In this code:

```java
command.name().toLowerCase(Locale.ROOT)
```

it converts enum names such as `TODO` to `todo` consistently, regardless of the computer’s language settings.

Without it:

```java
command.name().toLowerCase()
```

Java uses the machine’s default locale. This can produce unexpected results in languages with special capitalization rules—Turkish is the classic example, where uppercase `I` may lowercase to `ı` rather than `i`.

`Locale.ROOT` essentially means: “This text is program data, not text written in a particular human language.”

It is appropriate here because command words such as `todo`, `list`, and `delete` are fixed syntax.

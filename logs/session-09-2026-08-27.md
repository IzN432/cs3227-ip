- Added abstract `Task.toSerializedString()` with subtype-specific formats (`T | 0 | description`, `D | 0 | description | deadline`, `E | 0 | description | start | end`).
- Added `Task.fromSerializedString()` as a static factory validating type marker, completion status, and field counts.
- Implemented `Storage.loadTasks()`, returning an empty list on a missing directory or file.
- Propagated `IOException` directly; kept `EkkoException` for command validation only; switched malformed-data errors to `IllegalArgumentException`.

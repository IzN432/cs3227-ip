# Session 25 — 2026-09-01

## Topic
Pivoting the application domain from a task manager to a marketplace chatbot named Ekko,
and laying out the core domain model.

## Prompts
- Asked to delete `tasks/` and all related tests.
- Asked to take out storage first, then implement the first command: `becomeseller`.
- Asked to ensure tests are written for all new classes.
- Asked to commit two separate commits: one for classes, one for tests.

## Actions
- Deleted `Ekko.java`, `EkkoException`, the entire `task/` package, `storage/Storage.java`,
  `UiTest.java`, and removed `showTasks` methods from `Ui.java`.
- Replaced `AppException` as the project's exception type throughout the parser.
- Created the marketplace domain model:
  - `ekko.users.User` — username, hashed password placeholder, balance, seller flag.
  - `ekko.users.UserStore` — HashMap-backed store with `add`, `get`, `contains`, `authenticate`.
  - `ekko.listing.Listing` (abstract) — uuid, ownerUsername, name, description, state enum.
  - `ekko.listing.BinListing` — fixed-price listing with buyer tracking.
  - `ekko.listing.AuctionListing` — timed auction with `Bid` records and expiry logic.
  - `ekko.listing.Bid` — immutable value object: bidderUsername, amount.
  - `ekko.listing.ListingStore` — UUID-keyed store with active/owner/type queries and `search`.
  - `ekko.listing.AuctionProcessor` — pure logic class that resolves expired auctions without
    JavaFX dependency.
  - `ekko.ui.GuiUi` — wraps three lambdas for message output, error output, and confirmation.
  - `ekko.Marketplace` — command dispatcher; implemented `becomeseller`.
- Wrote `UserTest` (12 tests), `UserStoreTest` (11), `BidTest` (4), `BinListingTest` (8),
  `AuctionListingTest` (9), `ListingStoreTest` (24), `AuctionProcessorTest` (6).
- Committed domain model classes and tests in two separate commits.

## Outcome
The task manager is fully removed; the marketplace domain model is in place with comprehensive
test coverage; `becomeseller` is the first working command.
